**Verdicts:** SOLID (audited, reproduces, survives its own controls) · SUGG = SUGGESTIVE (measurement
solid, an interpretive clause is bounded or contested) · DEMO = DEMONSTRATION (near-tautological by
construction — existence proof, never an effect size) · PHD = POST-HOC-DESCRIPTIVE (no preregistered
test; direction only). **Prereg:** PRE = preregistered · POST = post-hoc · CTRL = preregistered negative
control · STR = structural check.

## Global scope — applies to every row, not repeated

| # | Condition |

| G2 | The "worldview" is a 2-bit XOR: both cues are sign-product rules on disjoint input coordinate pairs, searched equal-cost. Closed-form readability is a property of that generator. |
